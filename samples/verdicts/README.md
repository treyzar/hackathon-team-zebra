# Набор решений с ожидаемыми вердиктами

Проверка автоматической проверки целиком, на работающем стенде: API → очередь →
воркер → Judge0 → вердикт. Повторяет сценарий 2 критериев: верное, неверное
решение, ошибка выполнения и бесконечный цикл — плюс частичный балл.

## Задача `desks/` — «Парты»

Из демонстрационного курса «Первые программы на Python». Три класса, за партой
двое — сколько парт купить. Скрытые тесты разбиты на группы с баллами
(`scoring: per_group`, максимум 10): «чётные классы» — 4 балла,
«нечётные классы» — 6. Лимит времени — 1 секунда.

| Решение | Что в нём | Ожидаемый вердикт |
|---|---|---|
| `wrong_answer.py` | считает учеников, а не парты | `wrong`, 0 баллов, неверный ответ на 1-м тесте группы «чётные классы» |
| `runtime_error.py` | читает три числа из одной строки, а они на трёх | `wrong`, 0 баллов, ошибка выполнения на 1-м тесте |
| `time_limit.py` | бесконечный цикл | `wrong`, 0 баллов, превышено время на 1-м тесте; стенд продолжает работать |
| `partial.py` | забыл про нечётное число учеников | `partial`, 4 балла, неверный ответ на 1-м тесте группы «нечётные классы» |
| `correct.py` | верное решение | `correct`, 10 баллов |

Файлы: `task.json` — задача в формате API (`POST /api/admin/modules/{id}/steps`),
`solutions/` — решения, `expected.json` — ожидаемые вердикты (порядок важен:
верное решение последним, после полного балла новые попытки закрыты).

## Запуск

Нужна учётная запись администратора. Скрипт создаёт временный курс с задачей,
регистрирует временного ученика, отправляет решения по одному, дожидается
вердиктов, печатает «ожидали / получили» и удаляет курс
(`--keep` — оставить). Код выхода 0, если всё совпало.

С машины разработчика:

```bash
cd backend
ADMIN_PASSWORD=... uv run python scripts/check_verdicts.py \
  --api https://cifrovye-zodchie.ru/api --admin <логин администратора>
```

На сервере, внутри сети docker (без внешнего HTTPS):

```bash
cd ~/zebra/backend
docker compose -f docker-compose.prod.yml run --rm --no-deps \
  -v "$PWD/../samples:/samples:ro" -e ADMIN_PASSWORD=... backend \
  uv run --no-sync python scripts/check_verdicts.py \
  --api http://backend:8000/api --admin <логин> --set /samples/verdicts/desks
```

Пример вывода:

```
OK   wrong_answer.py
     ожидали:  wrong, 0 б., wrong_answer, группа «чётные классы», тест 1
OK   runtime_error.py
     ожидали:  wrong, 0 б., runtime_error, группа «чётные классы», тест 1
OK   time_limit.py
     ожидали:  wrong, 0 б., time_limit, группа «чётные классы», тест 1
OK   partial.py
     ожидали:  partial, 4 б., wrong_answer, группа «нечётные классы», тест 1
OK   correct.py
     ожидали:  correct, 10 б., ok

Совпало 5 из 5
```

Тот же набор прогоняется автотестом `backend/tests/test_verdict_set.py` —
там вместо Judge0 решения запускает локальный Python с тем же лимитом времени.
Временный ученик (`verdicts_…`) после проверки остаётся в базе.
