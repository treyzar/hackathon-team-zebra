# Zebra — платформа онлайн-обучения

Курсы состоят из модулей, модуль — из упорядоченных шагов. Шаг — это теория
или задание: одиночный выбор, множественный выбор, свободный ответ
(с файлами) или программирование на Python с проверкой тестами.

- **Ученик** проходит опубликованные курсы и отправляет решения.
- **Куратор** проверяет решения учеников своей группы.
- **Администратор** пишет курсы, управляет группами и ролями.

| Часть | Технологии |
|---|---|
| Бэкенд (`backend/`) | Python 3.12, FastAPI, SQLAlchemy (async), PostgreSQL, Alembic |
| Фронтенд (`frontend/`) | Vue 3, Pinia, Vite |
| Файлы | S3-совместимое хранилище (SeaweedFS), загрузка по presigned URL |
| Проверка кода | Judge0 1.13 (песочница isolate), воркер с очередью в Postgres |
| Прод | Docker Compose, Caddy (HTTPS от Let's Encrypt) |

## Локальная разработка

```bash
cd backend
cp .env.example .env        # заполнить секреты; JUDGE0_AUTH_TOKEN — с сервера
docker compose up -d --build
```

- API: http://localhost:8000 (документация: http://localhost:8000/docs)
- Фронтенд: http://localhost:5173
- Первый администратор:
  `docker compose exec dev uv run --no-sync python src/set_role.py <username> admin`

Код заданий по программированию проверяется на серверном Judge0
(`JUDGE0_URL` в `.env`): локально Judge0 не работает на Docker Desktop,
которому нужен cgroup v1.

### Тесты и линтер

```bash
cd backend
uv sync
uv run pre-commit install                 # один раз: ruff перед каждым коммитом
TEST_DB_URL="postgresql+asyncpg://user:pass@localhost:5432/app_test" uv run pytest
```

Без `TEST_DB_URL` запускаются только юнит-тесты. База из `TEST_DB_URL`
очищается при каждом запуске — не указывайте рабочую.
